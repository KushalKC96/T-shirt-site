# 21.dev Product Rail Gallery

This is a Vite + React + TypeScript project featuring a custom Product Rail Gallery component with Framer Motion animations and Tailwind CSS v4 styling.

## Prerequisites

- Node.js (v18 or higher recommended)
- npm

## Setup

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

   The app will be available at `http://localhost:5173/`.

3. **Build for production:**
   ```bash
   npm run build
   ```

## Key Configuration
- **Tailwind CSS:** Configured using the Vite plugin (`@tailwindcss/vite`).
- **Path Aliases:** The `@` alias maps to the project root for clean imports.
- **Styling:** Global styles and theme variables are defined in `app/globals.css`.
